# 跨境服务 APP 项目开发方案 (PRD + 技术方案)

## 1. 产品定位与目标
- **名称**: 跨境出海智库 (暂定)
- **定位**: 为中国商家提供一站式出海情报、合规与选品决策支持工具。
- **目标用户**: 已出海的企业家、计划出海的准企业家。
- **平台**: Web 网页版 + 移动端 App。

---

## 2. 核心功能模块

### 2.1 跨境智库 (Think Tank)
- **国别报告**:
  - 数据维度：GDP、人均GDP、总人口、劳动力占比(15-55岁)、城市化率、通电/通网率、FDI、中外贸易额及趋势（5年数据）。
  - 覆盖区域：北美、欧洲、亚太、新兴市场、中东、非洲、中亚等核心经济体。
- **行业趋势**:
  - 分类体系：基于中国海关核心一级出口分类。
  - 趋势维度：文化习惯、消费/基建/人口/社会/自然环境趋势。
- **风险预警**:
  - 内容：地缘政治动向、交通/供应链中断、目标国监管政策变动。

### 2.2 出海工具箱 (Toolbox)
- **合规查询**:
  - 逻辑：基于行业品类（如建材）匹配目标国准入要求。
  - 参考：集成《【内转外】-建材品类全球指导策略》中的转型建议与认证要求（如 UL, CE, ASTM, NSF 等）。
- **关税计算**:
  - 实现：根据 HS Code 和目标国自动计算预估税率。
- **AI 趋势选品**:
  - 聚合分析：Amazon、TikTok、Instagram、YouTube、Google Trends。
  - 产出：热搜关键词、爆款产品建议、AI 驱动的选品逻辑。

### 2.3 全球 80% 消费地图罗盘 (Core Algorithm)
- **功能**: 用户输入品类（如：户外储能），系统输出决策建议。
- **算法维度**:
  - **首选利润国**: 考量人均 GDP、消费力、高净值人群密度。
  - **首选规模国**: 考量总人口、电商渗透率、物流基建成熟度。
  - **首选蓝海国**: 考量中方出口增长率、进口替代空间、年轻人口红利。
- **一键匹配**: 直接关联对应的合规资质（VAT, EPR, GDPR 等）。

### 2.4 金融实时数据
- **实时汇率**: 人民币对美元、欧元、日元、澳元、加元、英镑。
- **现货行情**: 伦敦金实时价格。

## 3. 技术方案

### 3.1 技术栈推荐
| 端/层 | 建议选型 | 理由 |
|---|---|---|
| **前端 (Web)** | React + Tailwind CSS | 高开发效率，组件复用性强。 |
| **App** | Flutter 或 React Native | 一套代码同时发布 iOS 和 Android，性能优异。 |
| **后端** | Node.js (NestJS) 或 Python (FastAPI) | 适合处理高并发请求及数据爬取/处理。 |
| **数据库** | PostgreSQL + Redis | 关系型数据存储与高性能缓存。 |
| **数据源** | World Bank API, GoldAPI, ExchangeRate API | 保证数据的权威性与实时性。 |

### 3.2 数据获取策略
1. **宏观经济数据**: 通过 World Bank API 定期同步，存入本地数据库。
2. **实时金融数据**: 调用实时 API，前端缓存 1-5 分钟。
3. **选品趋势**: 使用 SerpApi 或类似聚合工具获取社交媒体和电商平台数据。
4. **合规数据**: 整理 Excel 内容入库，并建立动态更新爬虫机制。

---

## 4. 页面结构设计 (Site Map)
1. **首页 (Home)**: 全球消费地图罗盘入口、今日金价/汇率看板。
2. **智库中心 (Think Tank)**: 国别报告列表页、行业深度趋势。
3. **工具中心 (Tools)**: 合规查询、关税计算、AI 选品工具。
4. **预警中心 (Alerts)**: 全球风险资讯流。
5. **个人中心 (Profile)**: 我的关注国家/品类、已保存的报告。

---

## 5. 后续开发计划
1. **第一阶段 (MVP)**: 完成消费地图罗盘逻辑、基础国别报告、建材合规查询及实时汇率/金价。
2. **第二阶段**: 集成社交媒体选品趋势，扩展至更多行业合规数据（电子、服装等）。
3. **第三阶段**: 深度集成关税计算 API，上线多语言版本。
